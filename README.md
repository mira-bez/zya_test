# task1 — Конкурентный анализ цен и предложения по ценовой политике

---

## Цель задания
Провести конкурентный анализ ассортимента ЗЯ, рассчитать цену до скидки на основе
текущего справочника наценок и подготовить предложения по ценовой стратегии
в рамках цели компании — встать в минимальную цену на рынке при сохранении
маржинальности не ниже 10%.

---

## Входные данные
Используется Excel-файл `Тестовое_задание_Data_аналитик_ЦО_2025_.xlsx` со следующими листами:
- **«Данные для задачи 1»** — ассортимент ЗЯ, закупочные цены и минимальные цены конкурентов;
- **«Справочник наценок»** — правила расчёта наценок с указанием уровня детализации,
  периода действия и признака активности.

---

## Логика расчёта цены до скидки

### Применение наценки
Наценка применяется по дереву приоритетов, от более детального правила
к более общему, с использованием первого подходящего активного правила
на дату расчёта:

1. Продукт  
2. Бренд / Категория 3  
3. Бренд / Категория 2  
4. Бренд / Категория 1  
5. Бренд  
6. Сегмент / Категория 3  
7. Сегмент / Категория 2  
8. Сегмент / Категория 1  
9. Сегмент  

Если правило неактивно или дата расчёта не входит в период его действия,
оно не используется.

### Формула цены до скидки
Цена до скидки рассчитывается по формуле:
Цена_до_скидки = Цена_закупки × (1 + Наценка)

---

## Конкурентный анализ

### Минимальная цена конкурента
Для каждого SKU определяется минимальная цена среди конкурентов
и конкурент, предложивший эту цену.

### Индекс цен
Индекс цен рассчитывается по каждому конкуренту как отношение
нашей цены до скидки к цене конкурента:

Индекс_цен = Цена_до_скидки_ЗЯ / Цена_конкурента

Дополнительно анализируются:
- среднее и медианное значение индекса;
- доля SKU, где цена ЗЯ ниже цены конкурента.

---

## Проверка стратегии минимальной цены

### Условие маржинальности
Маржинальность определяется как:
Маржа = (Цена_продажи − Цена_закупки) / Цена_продажи

Минимально допустимая цена продажи при марже 10%:
Цена_мин_маржа10 = Цена_закупки / 0.9

### Логика рекомендации цены
- Целевая цена под стратегию «минимальная цена»:
  минимальная цена конкурента − 1 рубль.
- Рекомендованная цена:
  максимум из целевой цены и цены, обеспечивающей маржу ≥ 10%.
- Рекомендованная скидка рассчитывается относительно цены до скидки.

Для каждого SKU определяется возможность встать в минимальную цену рынка
без нарушения ограничения по маржинальности.

---

## Результаты расчётов
В рамках анализа формируются следующие файлы:
- `task1_item_level.csv` — результаты расчётов на уровне SKU;
- `task1_price_index.csv` — индексы цен по каждому конкуренту;
- `task1_segment_summary.csv` — сводка по сегментам рынка;
- `task1_issue_by_competitor.csv` — конкуренты, чьи цены чаще всего
  делают стратегию минимальной цены недостижимой.

---

## Ключевые выводы

- В сегменте **Люкс** стратегия минимальной цены в большинстве случаев достижима
  при сохранении маржинальности ≥ 10%.
- В сегменте **Массмаркет** стратегия часто недостижима из-за агрессивного
  ценообразования маркетплейсов.
- Основные конкуренты, ограничивающие возможность ценовой конкуренции
  при заданной маржинальности — **Ozon** и **Wildberries**.

---

## Предложения по изменению справочника наценок

1. **Выделить отдельную логику для маркетплейсов (Ozon, Wildberries)**  
   Для SKU, где минимальную цену задают маркетплейсы, целесообразно
   формализовать альтернативную стратегию (например, защита маржи вместо
   попытки стать минимальной ценой).

2. **Повысить детализацию правил для сегмента «Массмаркет»**  
   Рекомендуется снизить долю общих правил уровня «Сегмент» и
   расширить использование правил уровня «Бренд / Категория»,
   так как именно в массмаркете наблюдается наибольшее количество
   конфликтов между стратегией минимальной цены и ограничением по марже.

3. **Формализовать ценовую стратегию в справочнике**  
   Добавление явного признака ценовой стратегии (например,
   `min_price` / `margin_guard`) позволит заранее определять,
   для каких SKU допускается участие в ценовой конкуренции,
   а для каких приоритетом является сохранение маржинальности.

---

## Ограничения анализа
- Используется минимальная цена конкурента без учёта условий доставки
  и промо-механик.
- Анализ проводится на статичном срезе данных без учёта динамики цен во времени.
- Закупочная цена рассматривается как фиксированная.
